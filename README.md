# InSTaPath
To reproduce the results in the paper:

The input gene and image data are available [here](https://drive.google.com/drive/folders/1TqTM1tvJXF78CwwEu-voEE999xWaN1tL?usp=sharing).

Step 2: Construct spot-level gene and image-word matrices
