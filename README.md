# InSTaPath
**To reproduce the results in the paper:**

The input gene and image data are available [here](https://drive.google.com/drive/folders/1rn68MP50wD7vWTxHMCLgCV5dIgJSUdEe?usp=sharing).

---
**Demo using data from the HEST-1K dataset:**

1. step1_VQ_img_features.py: Extract image tokens and vector-quantized image words
2. step2_preprocess_img_gene.py: Construct spot-level gene and image-word matrices
3. step3_instapath_VisiumBC.py: Train the InSTaPath multimodal topic model
